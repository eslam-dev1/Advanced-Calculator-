# الحاسبة الذكية (Smart Calculator)

تطبيق حاسبة علمية متطور لنظام أندرويد، مبني باستخدام **Kotlin** و **Jetpack Compose**. يتميز التطبيق بتصميم عصري (Obsidian Dark) وأداء عالي، مع دعم لميزات متقدمة مثل الرسم البياني والنافذة العائمة.

## 🚀 المميزات الرئيسية

*   **الحاسبة العلمية:** دعم كامل للعمليات الحسابية والعلمية (Trigonometry, Logarithms, Powers, Factorials).
*   **الرسم البياني التفاعلي:** إمكانية رسم الدوال الرياضية (مثل sin, cos, x^2) مع ميزة التكبير والتصغير.
*   **النافذة العائمة (Picture-in-Picture):** استمر في استخدام الحاسبة فوق تطبيقات أخرى.
*   **محول الوحدات:** تحويل بين فئات مختلفة مثل الطول، الكتلة، المساحة، وغيرها.
*   **وضع المبرمج:** التحويل بين الأنظمة العددية (HEX, DEC, OCT, BIN).
*   **سجل العمليات:** حفظ تاريخ العمليات الحسابية مع إمكانية النسخ والحذف.
*   **تخصيص الواجهة:** إمكانية تغيير لون التمييز (Accent Color) من بين 6 ألوان جذابة.
*   **استجابة لمسية (Haptic Feedback):** تعزيز تجربة المستخدم عند الضغط على الأزرار.

## 🛠 التقنيات المستخدمة

*   **Language:** [Kotlin](https://kotlinlang.org/)
*   **UI Framework:** [Jetpack Compose](https://developer.android.com/jetpack/compose)
*   **Architecture:** MVVM (Model-View-ViewModel)
*   **Database:** [Room Persistence Library](https://developer.android.com/training/data-storage/room)
*   **Navigation:** Jetpack Navigation Compose
*   **Dependency Management:** Version Catalog (libs.versions.toml)

## 📦 متطلبات التشغيل

*   نظام أندرويد إصدار 8.0 (API Level 26) أو أعلى (لدعم PiP).
*   أحدث نسخة من Android Studio (Koala أو أحدث).

## 🔨 البناء والتشغيل

1. قم بعمل `Clone` للمستودع:
   ```bash
   git clone https://github.com/username/smart-calculator.git
   ```
2. افتح المشروع في **Android Studio**.
3. انتظر انتهاء مزامنة Gradle.
4. اضغط على **Run** لتشغيل التطبيق على محاكي أو جهاز حقيقي.
