# الحاسبة العلمية الذكية (Smart Scientific Calculator)

تطبيق آلة حاسبة علمية أندرويد متكامل ومصمم بأسلوب عصري فائق الجمال يدعم الحسابات القياسية والمتقدمة، مع سجل دائم للعمليات وتجربة مستخدم عربية سلسة.

---

### User Review & Critical Decisions

> [!IMPORTANT]
> تم تأكيد التفضيلات الأساسية التالية بناءً على إجاباتك في المرحلة السابقة:

- **نوع الآلة والميزات**: آلة حاسبة علمية متكاملة تتضمن العمليات الرياضية المتقدمة (دوال مثلثية sin/cos/tan، لوغاريتمات ln/log، أسس، جذور، مضروب n!، وثوابت π و e)، مع سجل تاريخي لحفظ ومراجعة واسترجاع العمليات الحسابية السابقة.
- **التصميم والنمط المرئي**: مظهر داكن عصري (Dark Obsidian & Neon Accents) بألوان تفاعلية مميزة لكل فئة من الأزرار (أرقام، عمليات أساسية، دوال علمية، زر النتيجة =)، مع دعم حركات انسيابية ومؤثرات ضغط مرنة.
- **اللغة وتنسيق الأرقام**: واجهة مستخدم كاملة باللغة العربية مع استخدام الأرقام القياسية العالمية (0-9) لضمان الدقة والوضوح التام في المعادلات الرياضية المعقدة.

---

### 1. Overview & Core Concept

- **ما يقدمه التطبيق**: واجهة حاسبة ذكية تفاعلية تتيح للمستخدم إنجاز العمليات اليومية البسيطة والعمليات الهندسية والعلمية بدقة فائقة. تعرض الشاشة العملية الحالية مع معاينة فورية للنتيجة قبل الضغط على "يساوي"، مع إمكانية التبديل بين الزوايا (درجات Deg / راديان Rad)، وسحب لوحة الدوال العلمية بسهولة.
- **الجمهور المستهدف**: الطلاب، المهندسون، والمستخدمون اليوميون الذين يحتاجون لحاسبة موثوقة، سريعة، وسهلة الاستخدام دون تعقيدات أو بطء.
- **القيمة المضافة**:
  - محرك تقييم تعبيرات رياضية حقيقي يدعم الأقواس وترتيب العمليات الرياضية (BODMAS).
  - سجل عمليات دائم (History) يتيح إعادة استخدام المدخلات أو نسخ النتائج بنقرة واحدة.
  - تجربة بصرية فائقة الانسيابية متوافقة مع Material 3 وEdge-to-Edge بالكامل.

---

### 2. User Experience & Visual Design

#### رحلة المستخدم والتفاعلات الأساسية (User Flows):
1. **شاشة الحساب الرئيسية**:
   - شاشة عرض علوية عريضة تتكون من سطرين: التعبير الرياضي الحالي وسطر المعاينة الفورية للنتيجة بخط ديناميكي يتكيف حجمه مع طول المعادلة.
   - شريط تحكم علوي يتيح: فتح سجل العمليات، تبديل وحدة الزوايا (Deg/Rad)، مسح الشاشة بالكامل (AC) أو حذف آخر خانة (Backspace/⌫).
   - لوحة أزرار سفلية تفاعلية مقسمة بذكاء للأرقام والعمليات الأساسية (+, −, ×, ÷, %).
2. **لوحة العمليات العلمية (Scientific Drawer / Toggle)**:
   - زر تبديل سريع يظهر اللوحة العلمية أو يدمجها بسلاسة: الدوال المثلثية (sin, cos, tan, inverse)، اللوغاريتمات (ln, log)، الأسس والجذور (x², xʸ, √, ³√)، الأقواس ( )، والمضروب (!)، والثوابت الرياضية (π, e).
3. **سجل العمليات الحسابية (History Bottom Sheet / Dialog)**:
   - نافذة منبثقة أنيقة تسرد كافة العمليات السابقة مع تاريخ وتوقيت الحساب.
   - النقر على أي عملية يعيد إدراجها فوراً في شاشة الإدخال.
   - إمكانية نسخ المعادلة أو النتيجة إلى الحافظة، أو مسح السجل كاملاً بضغطة زر.

#### الهوية البصرية ونظام الألوان:
- **الخلفية**: درجات أسود OLED فائقة العمق (`#0D1117` و `#161B22`) لتوفير استهلاك البطارية وإبراز تباين العناصر.
- **الأزرار الرقمية**: رمادي داكن ناعم (`#21262D`) مع نص ناصع ومريح للعين.
- **العمليات الرياضية الأساسية**: تدرجات برتقالية وكهرمانية حيوية (`#FF9500` / `#FFAA33`) لسرعة التمييز.
- **الدوال العلمية والوظائف الثانوية**: درجات النيلي والسيان الحديث (`#38BDF8` و `#6366F1`).
- **زر يساوي (=)**: تدرج زمردي مشرق جذاب (`#10B981`) يبرز كإجراء أساسي للحل.
- **الطباعة والمحاذاة**: حجم خط متكيف (Auto-sizing text) يتقلص كلما زاد طول المعادلة لمنع قطع الأرقام.

---

### 3. Key Product Decisions & Trade-Offs

1. **محرك التقييم الرياضي (Mathematical Parsing Engine)**:
   - *الخيار المعتمد*: محرك محلل تعبيرات رياضية (Parser & Evaluator) مخصص وآمن خوارزمياً (مبني على خوارزمية Shunting-yard / Recursive Descent) يعالج العمليات بالأولويات الرياضية الصارمة والدوال المعقدة.
   - *السبب*: تفادي ثغرات ومحدوديات مكتبات التقييم الخارجية، وضمان استجابة لحظية ومعالجة دقيقة للأقواس والعمليات المركبة بدون أخطاء تقريب.
2. **إدارة الحالة وتخزين السجل**:
   - *الخيار المعتمد*: نموذج MVVM متين (`CalculatorViewModel`) مع تدفقات `StateFlow`، وقاعدة بيانات Room محلية فائقة الخفة لحفظ السجل الدائم على الجهاز بدون أي حاجة للإنترنت.
   - *السبب*: تجربة فورية وسلسة بنسبة 100% بدون أي تأخير، مع بقاء عمليات المستخدم محفوظة حتى بعد إغلاق التطبيق.
3. **التجاوب والتصميم التكيفي (Edge-to-Edge & Safe Insets)**:
   - *الخيار المعتمد*: دعم كامل لـ Edge-to-Edge مع معالجة هوامش الكاميرا وشريط التنقل السفلي (`safeDrawingPadding`), وتوزيع مرن للأزرار (`Arrangement.spacedBy`, `Modifier.weight`).
   - *السبب*: ملاءمة كافة أحجام شاشات أندرويد الحديثة دون أي تداخل مع أزرار التنقل أو الحواف.

### 4. Technical Architecture & Data Strategy

```
│                       MainActivity                          │
│        (Edge-to-Edge, Material 3 Dark ColorScheme)          │
└──────────────────────────────┬──────────────────────────────┘
                               │
                               ▼
┌─────────────────────────────────────────────────────────────┐
│                    CalculatorScreen                         │
│  ┌───────────────────────────────────────────────────────┐  │
│  │ DisplaySection: Formula Input & Live Preview Result   │  │
│  ├───────────────────────────────────────────────────────┤  │
│  │ QuickControls: History, Deg/Rad Toggle, Clear, Delete │  │
│  ├───────────────────────────────────────────────────────┤  │
│  │ ScientificPad: sin, cos, tan, ln, log, √, ^, π, e, () │  │
│  ├───────────────────────────────────────────────────────┤  │
│  │ Numeric & Primary Keypad: [7-9, 4-6, 1-3, 0, ., =]    │  │
│  └───────────────────────────────────────────────────────┘  │
└──────────────────────────────┬──────────────────────────────┘
                               │ StateFlow Events & UI State
                               ▼
┌─────────────────────────────────────────────────────────────┐
│                   CalculatorViewModel                       │
│  - Input buffer & cursor state                              │
│  - Real-time Expression Evaluation & Formatting             │
│  - Deg/Rad mode toggle                                      │
│  - History management (Insert, Retrieve, Clear)             │
└──────────────┬──────────────────────────────┬───────────────┘
               │                              │
               ▼                              ▼
┌─────────────────────────────┐ ┌─────────────────────────────┐
│     MathExpressionParser    │ │     Room Local Database     │
│ - Shunting-yard evaluator   │ │ - CalculationHistoryEntity  │
│ - Scientific functions      │ │ - HistoryDao                │
│ - Operator precedence       │ │ - HistoryRepository         │
└─────────────────────────────┘ └─────────────────────────────┘
```

#### بنية البيانات الأساسية:
- `CalculatorUiState`: يحتوي على المعادلة الحالية (`expression`)، النتيجة الحالية أو المعاينة (`result`)، وضع الزوايا (`isDegreeMode`)، إظهار لوحة الدوال العلمية (`isScientificExpanded`)، وحالة الخطأ إن وُجدت.
- `CalculationHistory`: كائن يمثل العملية المسجلة (`id`, `expression`, `result`, `timestamp`).

### Verification & Testing Plan
- التحقق من دقة العمليات الحسابية القياسية والمعقدة (مثل: `5 + 3 * 2 = 11`, `sin(90) = 1` في وضع الدرجات, `ln(e) = 1`).
- التحقق من التعامل الذكي مع القسمة على صفر أو التعبيرات غير المكتملة.
- اختبار سلاسة الضغط على الأزرار مع التغذية الراجعة والاهتزاز الخفيف (Haptic feedback).
- اختبار حفظ واسترجاع ومسح سجل العمليات.
- تشغيل فحص البناء `compile_applet` لضمان خلو التطبيق من أي أخطاء تجميع.
